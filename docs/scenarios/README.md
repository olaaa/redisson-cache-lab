## Общее для всех сценариев

- Источник — `ProductSource`: читает БД с задержкой 50 мс (в тестах 100 мс), считает обращения и умеет падать. Главная проверка каждого теста — `source.callCount()`.
- Перед каждым тестом `ScenarioTestSupport` очищает таблицу, вставляет «Чайник» (id 1, 2490.00), очищает базу Redis, локальные копии и сбрасывает счётчик.
- Вторая реплика в тесте — отдельный `RedissonClient` к тому же Redis: свои соединения и своя локальная копия.
- Посмотреть, что лежит в Redis, тест может командами `redis-cli` внутри контейнера (`redisCli(...)`), а вручную — через `docker compose exec redis redis-cli`.
